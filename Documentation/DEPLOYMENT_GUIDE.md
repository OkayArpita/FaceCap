# Deployment Guide

## Local Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Metro:
   ```bash
   npm run start
   ```
3. Run Android/iOS build:
   ```bash
   npm run android
   npm run ios
   ```

## Hackathon Demo Flow
1. Enroll a user from the Enrollment screen.
2. Verify the user from the Verification screen.
3. Turn network off and create records.
4. Open Sync screen, restore network, and run Sync now.
5. Show queue reduction and sync history updates.
